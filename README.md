# 🚀 Planix — Modern CRM Dashboard

![Next.js](https://img.shields.io/badge/Next.js-16-black)
![React](https://img.shields.io/badge/React-19-blue)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)
![License](https://img.shields.io/badge/license-MIT-green)

**Planix** is a modern, scalable CRM dashboard built with cutting-edge frontend technologies.
Designed as a solid foundation for SaaS platforms, admin panels, and internal tools.

---

## ✨ Key Features

- 📊 **Analytics Dashboard** — visual insights & metrics
- 👥 **Client Management** — organize and track customers
- 📁 **Project System** — manage projects efficiently
- ✅ **Task Management** — scalable task workflows
- 📬 **Inbox UI** — messaging & notifications interface
- 🌐 **Internationalization** — multi-language support (i18n)
- ⚙️ **Settings System** — flexible user configuration
- 📱 **Responsive Design** — works on all devices
- 🎨 **Modern UI Kit** — clean, consistent design system

---

## 🧠 Why Planix?

Unlike typical UI templates, Planix is built as a **real application architecture**.

- 🧱 Feature-based structure (not just components)
- ⚡ Ready for real backend integration
- 📈 Scales with product growth
- 🧩 Clean and maintainable codebase
- 🚀 Ideal for MVPs and SaaS startups

## ⚡ Quick Start

```bash
git clone https://github.com/your-username/planix.git
cd planix
pnpm install
pnpm dev
```

App will be available at: <http://localhost:3000>

---

## 🏗 Production

```bash
pnpm build
pnpm start
```

---

## 📁 Project Structure

```
/app            # Next.js App Router
/components     # Reusable UI
/features       # Business logic modules
/hooks          # Custom hooks
/lib            # Utilities
/public         # Static assets
/styles         # Global styles
```
